# Sloane Davidson — Technical Program / Product Portfolio

A responsive React website built with Vite. Includes an introductory page, project filters, three interactive case studies, about/expertise sections, and a resume download.

## Run locally

1. Install [Node.js](https://nodejs.org/) (Node 20.19+ or 22.12+ recommended).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address shown in the terminal.

## Deploy for free (no custom domain required)

1. Push this folder to a GitHub repository.
2. Sign in to [Vercel](https://vercel.com/) and import the repository.
3. Vercel normally detects Vite; use **Build command** `npm run build` and **Output directory** `dist` if asked.
4. Deploy to the provided `.vercel.app` address.

A custom domain is optional; the exact free subdomain is subject to availability.

## Personalize before sharing

- `src/App.jsx`: update the introduction, project results, and add a contact email and/or LinkedIn link in the contact section.
- `src/App.jsx`: confirm eCR client count and historical 76% outcome before presenting it as a current result.
- `src/App.jsx`: replace suggested artifacts with actual sanitized examples when ready.
- `public/Sloane_Davidson_Resume.pdf`: replace with your preferred TPM-targeted resume; the bundled PDF is your existing master resume.
- `src/styles.css`: edit typography, colors, and spacing.

## Privacy and accuracy

Do not publish federal/internal architectural diagrams, confidential client details, protected health information, unpublished company documentation, or unsupported KPIs. This portfolio avoids claiming formal TPM ownership of the Oracle modernization work.
